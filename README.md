# Network Topology Design and Simulation using Cisco Packet Tracer

## 📌 Project Overview

This project demonstrates the design and simulation of different computer network topologies using **Cisco Packet Tracer**.

The project includes four network topologies:

- **Bus Topology**
- **Star Topology**
- **Ring Topology**
- **Hybrid Topology**

The project demonstrates how computers and network devices can be interconnected and how network communication can be tested and analyzed using Cisco Packet Tracer.
---
## 🎯 Objectives

The main objectives of this project are:

- To understand different types of network topologies.
- To design network topologies using Cisco Packet Tracer.
- To configure IP addresses and subnet masks for network devices.
- To understand communication between devices through network switches.
- To test connectivity using **ICMP/Ping**.
- To observe packet movement using **Simulation Mode**.
- To understand basic networking protocols such as **ARP and ICMP**.
- To perform basic network connectivity troubleshooting.

---

## 🖥️ Network Topologies Implemented

### 1. Bus Topology

In a Bus topology, multiple devices are connected through a common communication path.

**Key concept:**
- Devices share a common network segment.
- It is simple to design and understand.
- Network communication can be tested between connected devices.

---

### 2. Star Topology

In a Star topology, multiple computers are connected to a central network switch.

**Key concept:**
- The central switch manages communication between connected devices.
- Failure of a single end-device connection does not normally affect other devices.
- It is commonly used in modern LAN environments.

---

### 3. Ring Topology

In a Ring topology, network devices are connected in a circular arrangement.

**Key concept:**
- Each device forms part of a closed network path.
- Network traffic can travel through connected devices.
- The topology demonstrates how redundant connections can be handled in a switched network.

---

### 4. Hybrid Topology

A Hybrid topology combines characteristics of multiple network topologies.

**Key concept:**
- Different topology structures can be combined.
- It can be designed according to network requirements.
- It demonstrates how multiple network structures can work together.
